# End-to-End (E2E) Tests

Playwright / Cypress test suites covering end-to-end user journeys:
1. User registration, phone OTP verification, and JWT session issuance.
2. Ad creation, image upload to MinIO/S3, and ad publication.
3. Buyer-seller chat flow, realtime messaging over Socket.IO, and push notifications.
4. Admin verification, moderation, and media cleanup.
