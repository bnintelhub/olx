# Grafana Dashboards

Store JSON dashboard definitions here:
- `api-performance.json`: RPS, p50/p95/p99 latency, 5xx error rates, active connections.
- `database.json`: PostgreSQL connections, cache hit ratio, slow queries, transaction rate.
- `redis.json`: Redis memory usage, ops/sec, connected clients, cache hits/misses.
- `workers.json`: BullMQ active jobs, failed jobs, throughput, queue latency.
